01

From a report tool

The four importers are plain JavaScript with no server calls: the same source the ReportWright server uses, bundled for this page. Your file is read with the browser's File API and never uploaded; open the network tab to check. Data sources that run SQL need the ReportWright server, so a SQL-backed report previews its layout with no rows.

No file to hand? Try a sample

Samples are unmodified files from the repository's test corpus: Microsoft's SSRS samples (MIT), JasperReports demos (LGPL-3.0), BIRT samples (EPL-2.0), and our own ActiveReportsJS-format files.
