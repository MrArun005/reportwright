● Report designer · viewer · engine

Pixel-exact business reports, laid out in the browser.

Pagewright is an MIT-licensed alternative to ActiveReportsJS: a banded report designer, a viewer you embed with one call, and an engine that lays out every line itself, so the screen, the PDF and the printout match. Every report on this page is rendered live, in this tab. There is no server behind this site.

    What it does today
    
      
    From the project's status document. Everything listed runs and is covered by tests; the right-hand column is what it does not do yet.
    
    
    
    
    
      
    Layout engine
    Page bands, multi-column body, keep-together and keep-with-next, page breaks between groups, table of contents with final page numbers, galley (pageless) view. Pure JavaScript with no DOM, so the same code renders in the browser and in Node.
    
      
    Data
    JSON, CSV, REST, GraphQL, and SQL run on the server (SQLite, Postgres, MySQL). A response explorer finds the rows in an API response. Filters, sorts, lookups, nested data sets, report functions.
    
      
    Interactivity
    Parameters with sliders, ranges, date ranges, cascading lists and options from data. Collapsible groups whose totals and paging stay correct, click-to-sort headers, drill-through with a breadcrumb, document map, search.
    
      
    Visuals
    Column, bar, line, area, pie, donut and scatter charts; pivot matrix with totals; sparkline, data bar and bullet in table cells; 49 barcode symbologies as vectors; rich text with lists, links and mixed styles; rotated and vertical text.
    
      
    Output
    PDF with links and an outline, Excel, Word (real tables), HTML and CSV from the viewer. On the server: every format by URL, batches, schedules with time zones, signed webhooks, API keys, and a pw CLI that renders and diff-tests reports in CI.
    
      
    Designer
    Smart guides, rulers, align and distribute, groups, sort and filter editors, table and matrix gallery, drag a data set to get a table, themes and named styles, version history, an expression editor with completion.
    
      
    Languages
    Viewer UI in English, Hindi, Spanish, French, German, Japanese, Chinese, Portuguese (BR) and Arabic (right-to-left). Report text is shaped with HarfBuzz, with bundled Noto fallbacks for Devanagari, Arabic and Hebrew.
