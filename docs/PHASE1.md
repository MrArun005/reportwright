## Exit test

`tests/e2e/build-from-scratch.mjs` creates a new report and, using only the designer UI: adds a parameter, a REST source and a data set (fields detected), drops a table, binds fields by drag-and-drop, adds a footer total, moves an item with the mouse, deletes and undoes, saves, previews and exports a PDF.

`scripts/check-pdf-matches-model.mjs` checks the 300-row sample: **2,237 text lines on 8 pages, 0 mismatches** between the page model and the PDF (position within 0.6 pt). The viewer draws the same lines from the same model.

## Honest gaps

1. **The full loan-statement sample was generated by `scripts/make-sample.mjs`, not built by hand in the designer.** The e2e test builds a smaller statement through the UI. Every feature the full sample uses is available in the designer.
2. **PDF size.** pdf-lib's font subsetter drops glyphs with Inter, so fonts embed in full: the 8-page sample is ~780 KB. Fix later with a different subsetter (for example HarfBuzz `hb-subset` in WASM).
3. **Expression editor** is a textarea with insert lists, syntax check and a live preview. CodeMirror completion is not in yet.
4. **Repeated table headers** shift everything on a continued page down by the header height, including items beside the table.
5. **Body text boxes** outside a table read the first row of their data set (`dataSet` property, default = first data set). Use `First(...)` / `Sum(...)` with a scope for clarity.
6. **Growth under 1 pt is ignored** (a text box that needs 14.6 pt in a 14 pt box does not push items below). This avoids cascades of hair-line shifts.
7. **Not in Phase 1 (as planned):** groups and subtotals, list/container, charts, matrix, Excel/HTML export, drill-down, smart guides, copy/paste between reports, multi-user storage.
